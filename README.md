# نظام تحديثات نداء الصلاة

هذا المستودع مخصص لملف معلومات الإصدارات الذي يقرأه تطبيق **نداء الصلاة** للتحقق من وجود تحديث جديد.

## الملفات

- `version.json`: رقم أحدث إصدار، رابط التنزيل، عنوان ورسالة التحديث.
- `index.html`: صفحة تعريفية بسيطة لـ GitHub Pages.

## رابط ملف التحديثات بعد تفعيل GitHub Pages

`https://lsisil140-debug.github.io/Nidaa-Salah-Updates/version.json`

## إعداد الإصدار الأول

الإصدار الحالي مضبوط على `1.0.0`، ورابط التنزيل فارغ عمدًا لأن التطبيق لم يُنشر بعد.

عند نشر أول إصدار، اترك الرقم `1.0.0` كما هو وأضف رابط صفحة التنزيل الفعلي عند توفره. وعند إصدار نسخة أحدث، حدّث قيمة `latestVersion` ورابط `downloadUrl` ورسالة التحديث في `version.json`.

## تنبيه

يجب أن يطابق تنسيق الحقول في `version.json` ما يقرأه التطبيق. يجب دمج رابط الملف داخل التطبيق، كما يجب تفعيل GitHub Pages من إعدادات المستودع حتى يصبح الرابط أعلاه متاحًا عبر الويب.
